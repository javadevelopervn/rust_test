# Introduction

This document provides an introduction to the Rust Load Tester, a simple, configuration-driven load testing tool written in Rust.

## What is it?

The Rust Load Tester is a command-line tool that allows you to define and execute load tests against your services. The tests are defined in a simple YAML file, which makes it easy to create and manage your test plans.

## Why was it built?

The tool was built to provide a simple and extensible way to perform load testing. While there are many great load testing tools available, this tool is designed to be lightweight and easy to use, with a focus on simplicity and extensibility.

## Who is it for?

This tool is for developers and QA engineers who need a simple way to perform load testing on their services. It's also for anyone who wants to learn more about Rust and how to build a command-line tool.
